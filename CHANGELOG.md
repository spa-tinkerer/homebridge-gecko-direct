# Changelog

## 1.0.0

First public release.

- Thermostat with water temperature, setpoint and heating status
- Up to two jet pumps as fans (50% = low, 100% = high)
- Lights, optional blower, and five watercare mode switches
- Local UDP connection to the in.touch2 home module, with automatic reconnection
- Supported spa packs: inXE, inYT, inYE, inYJ
- Settings window in the Homebridge UI
